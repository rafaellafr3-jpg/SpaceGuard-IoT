# SpaceGuard IoT

Sistema IoT para monitoramento de cápsula espacial.

## Objetivo
Monitorar condições críticas da cápsula espacial em tempo real.

## Sensores Utilizados
- TMP36 (Temperatura)
- LDR (Luminosidade)
- Sensor de Inclinação (Vibração)

## Componentes
- Arduino Uno
- Protoboard
- LEDs
- Resistores
- Sensores

## Funcionalidades
- Alerta de temperatura acima de 30°C
- Alerta de luminosidade elevada
- Alerta de vibração/inclinação
- Monitoramento em tempo real via Serial Monitor
